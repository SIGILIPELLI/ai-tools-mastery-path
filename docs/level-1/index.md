# Level 1 · Entry <span class="level-badge">Foundations</span>

Goal: build a working map of the AI tools landscape, learn a repeatable way
to pick the right tool for a task, and get hands-on with the major
categories — chat assistants, writing/research help, coding assistance,
image and media generation, and productivity automation. You'll also learn
prompting fundamentals that transfer across tools and habits for evaluating
AI output critically. You'll finish with a real deliverable: a personal AI
toolkit with a written justification for each tool you chose.

By the end of this level you'll be able to name the major categories of AI
tools, pick between them with a repeatable framework instead of guesswork,
write prompts that get better results from any of them, and catch the
common ways AI output goes wrong before it causes a problem.
